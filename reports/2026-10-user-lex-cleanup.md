# user-lex.csv の棚卸し（#41・#47）

辞書 v3.2 の上で、user-lex.csv（740行）を1行ずつ検証した。読みを変えない行・誤読を作る行を消し、
熟語を巻き込む行はコストを上げた。行ごとの結果は `reports/user-lex-cleanup-2026-10.tsv`。

## やり方

`scripts/audit-rows.ts` で、1行ずつ「その行を抜いた CSV」で文を読み直し、読みが変わる文を数えた。
ユーザー辞書の行はその表層を含む文にしか効かないので、表層を含む文だけを読み比べる。

読み比べた文:

- `eval/corpus/round1〜11.tsv`（1864件）
- `scripts/regression.test.ts` の「ユーザー辞書で誤読が直る」の文。#41 に挙がった4文を先に足した
- KWDLC（Web の文 10,716件。手元でのみ使った。`eval/README.md`）
- 行の表層そのもの（1語だけの文）

Tatoeba の比較コーパスは、まだこのリポジトリに入っていない。この環境からも取れなかったので使っていない。

`--remove-unchanged` を付けると、読みがどれも変わらなかった行をその場で抜き、抜いた後の CSV を基準に次の行を調べる。
2行が同じ文を支えている場合、1行ずつの結果を見てまとめて消すと読みが崩れるが、順に抜けばこれは起きない。

#41 で「v3 で不要」をまとめて消したときに6件が誤るようになったのは、監査表の分類を単独の語の読みで決めていて、
文の中で効いている行（風・熊が・一日・犬が 等）を拾えていなかったため。これらの行は外すと読みが変わるので、今回は残した。

### 外しても読みが変わらない行（526行を削除）

監査表（`user-lex-audit-2026-10.tsv`）で「v3 で不要」とした562行のうち526行。上の文のどれを読んでも、
外す前と後で読みが同じだった。v1（v7800n-slim2）の接続表の偏りを埋めていた行で、v3 では役目を終えている。
例: かき氷・夜空・背中・提灯・大会、の中で・な中で 等の文脈エントリ、聞き・星・港・殺し・入っ・な。

### 誤読を作っていた行（17行を削除）

外すと直る文があり、壊れる文が無かった行。

| 行 | 外すと直る読み |
|---|---|
| 書か | 聖書からの一節 → せい**か**からのいっせつ（#41） |
| 楽し | 楽しく時を過ごした → たのしく**じ**をすごした（#41） |
| 一人 | 一人暮らし → ひとり**くらし**（#41）。一人前 など18語の巻き込みも消えた（#47） |
| 大人 | 大人気 → **おとなき**、大人買い → おとなかい（#47） |
| 様 | この様な・今日の様に → この**さま**な・きょうの**さま**に |
| 屋台・一部・人生・力・強さ | 名古屋台地・一部屋・浪人生・力動感・力強さ を割っていた |
| の人は・その人 | 他の人は → **たの**ひとは、その人形劇 → そのひとけいげき |
| 犬の・犬で | 大型犬の・狩猟犬で → 〜**いぬ**の・〜**いぬ**で |
| 正直・神宮・安心 | 正直者・神宮寺・安心院 を割っていた（#47） |

「一日中家にいた」→ いちにち**なかや**（#41）は、`一日` の行が「一日中雨が降っていた」など5文を支えているので
消せなかった。代わりに `一日中,イチニチジュウ` の行（-14624）を足した。巻き込みは無い。

### 熟語を巻き込んでいた行（#47）

#47 の44行のうち37行は、上の2つ（読みが変わらない・誤読を作る）で消えた。残りの7行:

| 行 | 対応 | 理由 |
|---|---|---|
| 入れ | コスト 376 → **9376** | 巻き込み51語が0になる最小の段。入れ替わり→いれ**が**わり も直る |
| 日向 | コスト -14624 → **7376** | 巻き込み9語（小日向 等）が1語（日向臭）に減る。8376 なら0語だが、文末の 日陰と日向 が ひかげとひ**むか** になる。日向ぼっこ・日向で 等は変わらない |
| 中城 | コスト -14624 → **-624** | 巻き込み（金武中城）が0になる最小の段 |
| 水道 | **水道管** の行（2376）に置き換え | 水道 の行は 上水道→うえすいどう・下水道→したすいどう・水道水→すいどうみず を作っていた。行が無いと 水道管→みずどうかん になるので、そこだけ残した |
| 光っ・語っ | 削除 | 文の中（光った・語って・夢を語った 等）では行が無くても同じ読み。1語だけのときの読みしか変わらない |
| 私 | **残した** | 巻き込みは 私史（しし）の1語だけ。コストを 7376 に上げると、私は・私の を含む160文が わたくし 等に変わる |

## 残っているもの

- 私 → 私史、日向 → 日向臭 の巻き込み（各1語）。どちらもまれな語なので、許可リストには載せずに残した
- 本番のお題・承認済みの報告では検証していない（#29 は本番 D1 から読み取って使った）。代わりに KWDLC 1万文で、
  正解から誤りに変わる文が無いことを確かめた。消した行は、どれも「外しても読みが変わらない」か「外すと直るだけ」
- Tatoeba の比較コーパスが入ったら、`bun scripts/audit-rows.ts <tatoeba.tsv>` で同じ検証をし直す
