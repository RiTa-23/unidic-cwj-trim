# KWDLC（Web の文）での実測（2026-10）

`eval/corpus` は HENGE のお題に合わせて作った文なので、それ以外の自然な文でも測った。
使ったのは KWDLC（京都大学ウェブ文書リードコーパス）で、Web ページの冒頭3文に人手の形態素情報（読みを含む）が付いている。

KWDLC は研究目的の公開で、元の文書の著作権者の許諾は得ていない（README）。**文はリポジトリに入れず、手元で測った数字だけを残す。**
変換は `eval/kwdlc2tsv.py`。

## 方法

- 16,051文のうち、HENGE のお題と同じ条件（かな・漢字・句読点だけ）で漢字を含む 10,716文を使った。かなで中央値34字
- 期待の読みは KWDLC の読み（JUMAN の体系）。UniDic と付け方が違う語がある（他の＝たの、私＝わたくし、株式会社＝かいしゃ/がいしゃ の混在）。
  下の正解率はその差も誤りに数えているので、自作コーパスより厳しめに出る

## 多かった誤り（v3.1 ＋ user-lex の 1,694文）

| 誤り | 文数 | 例 |
|---|---|---|
| 日本 → にっぽん | 175 | 日本の企業 → にっぽんのきぎょう |
| 〜の方（かた）→ ほう | 135 | 初めての方でも → はじめてのほうでも |
| 〜会社 が濁らない | 58 | 証券会社 → しょうけんかいしゃ |
| 〜日（び）→ ひ | 52 | 開催日 → かいさいひ |
| 何 → なん | 49 | 何か面白い → なんかおもしろい |
| 〜曜日 → ようひ | 23 | 月曜日 → げつようひ |

どれも UniDic の値そのものに由来する。UniDic の全語彙を MeCab と同じ接続表（dense）で載せた辞書でも、同じ文をまったく同じに誤った。

- 日本: `ニッポン`（-2903）が `ニホン`（-1870）より安い
- 何: `ナン`（-310）が `ナニ`（-49）より安い
- 会社・日・布団・使い: 濁音形の行が基本形と**同じ lid/rid** で、コストだけ少し高い（会社 +76、日 +457、布団 +1228）。
  接続の条件が同じなので、文脈によらず基本形が勝つ（`filter_lex_v3.py` の規則6は、濁音形の方が安い組だけを扱っていた）
- 月曜日・開催日: 1語の項目が無く、月曜＋日（ヒ）に割れる

## ユーザー辞書で直したもの

1語の読みの好みや例外は user-lex.csv で直した（15行）。

- `日本,ニホン`: ニホンの行と同じ lid/rid で、ニッポンの行より安いコスト（2000）
- 月曜日〜日曜日（-14624）
- 何か・何を・何も・何が（-14624。8376 では ナン に負けた）、何時＝ナンジ（2000）
- 何時の行が 何時頃→なんじころ・何時何時→なんじなんじ を壊すので、何時頃＝ナンジゴロ・何時何時＝イツイツ も足した。
  何時頃 は UniDic の いつごろ から なんじごろ に変わるので `collateral-allow.tsv` に載せた

KWDLC は 84.1% → 86.2%（直った文 219、悪化1。悪化は話し言葉の「なんか」を なにか と読んだ文）。
`eval/corpus`（1864件）は 1770 → 1771件で、悪化0。

## 辞書 v3.2: 濁音形の付け替えを広げる

濁音形が基本形と同じ lid/rid で少し高い組（会社/ガイシャ +76、通り/ドオリ +102、時計/ドケイ +211）は、
名詞の後でも基本形が勝つ。1語ずつ足すと際限がないので、`filter_lex_v3.py` の規則6（濁音形の lid を接尾辞のものに
替えて +1500）を、濁音形が基本形より一定値まで高い組にも当てた（規則9）。上限を変えて比べた（user-lex 込み）:

## 1語では直せないもの

- 〜の方（かた/ほう）: 「初めての方でも」は かた、「こちらの方が」は ほう。文脈で決まるので保留
- 日→び（開催日・記念日）: 規則で拾うと 寺→でら・土日→どび を巻き込む。よく出る語はユーザー辞書で足す

## 誤配信と却下を分けた数え直し（v3.2 ＋ user-lex）

上の正解率は、KWDLC の読みと1字でも違えば誤りに数えている。HENGE で困るのは**誤った読みが配信される**ことで、
読みが無く UNKNOWN_READING で却下されるのは安全側、KWDLC と付け方が違うだけの別解は誤りではない。そこで3つに分けた。

- 文を KWDLC の形態素と辞書のトークンの、両方に共通する切れ目でブロックに分け、読みの違うブロックを取り出した
  （1,616か所、939通り）
- 939通りを1つずつ見て、別解（他の＝たの/ほかの、その後＝そのご/そのあと、〜所＝じょ/しょ、株式会社＝かいしゃ/がいしゃ、
  なぁ/なあ、KWDLC 側の誤記 等）185通りと、誤り754通りに分けた。判定は1人で、文脈は代表の1文で見ている
- 1文に誤りのブロックが1つでもあれば誤配信とした

| 分類 | 文 | 割合 |
|---|---|---|
| 一致 | 9,305 | 86.83% |
| 別解だけが違う | 272 | 2.54% |
| **誤配信** | **1,133** | **10.57%** |
| 却下（UNKNOWN_READING） | 6 | 0.06% |

誤配信の多いもの（か所）: 〜の方 かた→ほう 139、行って おこなって→いって 24、〜日 び→ひ 23、気に入り→きにはいり 18、
一 いっ→いち 16、御礼 おれい→ごれい 14、〜場 じょう→ば 11。残りの大半は地名・人名・寺社名の1回きりの誤り。

user-lex を重ねて一致するようになった文が 461、逆に user-lex を外せば一致する誤配信の文（user-lex が壊したもの）が 27 あった。
27文の原因は 大人＝オトナ（大人気→おとなき 7）、犬が・犬の 等（大型犬の→おおがたいぬの）、様＝サマ（どの様な→どのさまな）、
力＝チカラ、一部＝イチブ（一部屋→いちぶや）、人生＝ジンセイ（浪人生→なみじんせい）、その人＝ソノヒト、強さ＝ツヨサ。

### user-lex の害のある行を消す

上の27文の原因の行を1行ずつ外して測った（KWDLC を文書単位で半分に分け、片方（dev）と `eval/corpus` で決めて、もう片方（test）で確かめた）。
外して良くなったのは 大人・人生・力・様・強さ・この人・の人は・る中で・入って と、表層+助詞の 犬が〜犬まで・熊が〜熊まで（22行）。
犬・熊 は辞書だけで いぬ・くま と読めるので、熟語（大型犬・狩猟犬・白熊）を割る害だけが残っていた。要る語は語ごとに足した
（柴犬・白熊・北極熊・一人暮らし）。語っ は 物語って・語っている に要るので、強制勝ち（-14624）から 8376 に下げた（英語って→えいかたって を直す）。
他の＝ホカノ は外すと KWDLC は13文上がるが、KWDLC の付け方（たの）に寄るだけなので残した。

| | KWDLC dev（5,316） | KWDLC test（5,400） | eval/corpus（1,864） |
|---|---|---|---|
| 前 | 86.47% | 87.19% | 95.17% |
| 後 | 86.76% | 87.41% | 95.23% |

悪化した文は3つとも0。`reports/user-lex-audit-2026-10.tsv` で「v3 で不要」とした残りの約550行は、外しても KWDLC・eval/corpus の
どちらでも読みが変わらない行が大半だが、一日・風・花園・水道・境内 のように文脈では効いている行もあるので、一括では消していない。
